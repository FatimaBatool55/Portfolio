# Fatima Batool AI Engineer Portfolio

A modern personal portfolio website designed and developed to showcase my professional work as an AI Engineer.

Live Link: https://portfolio-three-gamma-g9b215fidu.vercel.app/

## About The Project

This portfolio was built from scratch with a focus on a modern, minimal, and interactive user experience. The design uses a dark visual theme, responsive layouts, custom animations, hover effects, and smooth scrolling to create a polished portfolio experience.

## Technologies Used

HTML5

CSS3

JavaScript

Custom CSS animations

Responsive web design

## Development

The website was developed using HTML, CSS, and JavaScript. The layout, styling, animations, responsive behavior, buttons, navigation, and visual interactions were customized specifically for the portfolio.

The website uses a responsive design approach so that the layout adapts to different screen sizes including desktop, tablet, and mobile devices.

## Deployment

The project is hosted on GitHub and deployed through Vercel.

GitHub is used for version control and storing the project source code, while Vercel is connected to the GitHub repository for deployment.

Whenever changes are pushed to the GitHub repository, Vercel can automatically build and deploy the updated version of the website.

## Project Structure

The project is primarily built around the main HTML file along with the required styling and assets used by the website.
